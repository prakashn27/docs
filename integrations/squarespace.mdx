## How to Add the Widget Script

1. Go to **Settings > Developer Tools > Code Injection**.
2. Paste the following script into the **Footer** text area:

```html
<script>
  window.supportUnicornSettings = {
    widgetToken: 'wgt_YOUR_TOKEN_HERE',
  };
</script>
<script src="https://your-support-unicorn-instance.com/sdk.js"></script>
```

3. Click **Save**.

<Warning>
  Code Injection requires a **Business** or **Commerce** plan. It is not available on the Personal plan.
</Warning>
