## How to Add the Widget Script

<Warning>
  The Custom Code feature requires a **paid Wix Premium plan**. It is not available on the free plan.
</Warning>

1. Go to your **Wix Dashboard**.
2. Navigate to **Settings** in the left-hand menu.
3. Scroll down to the **Advanced** section and click **Custom Code**.
4. Click **+ Add Custom Code** at the top right.
5. Paste the following script into the text box:

```html
<script>
  window.supportUnicornSettings = {
    widgetToken: 'wgt_YOUR_TOKEN_HERE',
  };
</script>
<script src="https://your-support-unicorn-instance.com/sdk.js"></script>
```

6. Give it a name (e.g., "Support Unicorn Widget").
7. Under **Place Code in**, select **Body - End**.
8. Under **Add Code to Pages**, select **All Pages** (or choose specific pages).
9. Click **Apply**.
