## What is Support Unicorn?

Support Unicorn is an AI-powered customer support platform that enables organizations to:

- **Deploy AI agents** that answer customer questions using knowledge bases
- **Provide multi-channel support** through Live Chat, SMS/WhatsApp, Slack, and Zendesk
- **Seamlessly escalate** to human agents when needed
- **Manage conversations** in real-time with WebSocket connections

## Core Purpose

Enable organizations to deploy AI agents that can answer customer questions using knowledge bases, with seamless escalation to human agents via various channels.
