## How to Add the Widget Script

1. Go to **Settings > Developer Tools > Code Injection**.
2. Copy your widget script from your agent's **Channels** page at [supportunicorn.com](https://supportunicorn.com) and paste it into the **Footer** text area.

3. Click **Save**.

<Warning>
  Code Injection requires a **Business** or **Commerce** plan. It is not available on the Personal plan.
</Warning>
