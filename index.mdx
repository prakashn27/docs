## What is Support Unicorn?

Support Unicorn is a Rails 8.0.2 AI-powered customer support platform that enables organizations to provide multi-channel customer support through Live Chat, SMS/WhatsApp (via Twilio), Slack, and Zendesk integrations. The platform uses Retrieval-Augmented Generation (RAG) with vector search for AI-powered responses.

## Architecture Highlights

### Technology Stack

- **Backend**: Ruby 3.4.4, Rails 8.0.2
- **Database**: PostgreSQL (primary), SQLite (for SolidCache, SolidQueue, SolidCable)
- **Job Processing**: SolidQueue
- **Real-time**: ActionCable (SolidCable)
- **Frontend**: Hotwire (Turbo + Stimulus), Importmap
- **AI/ML**: OpenAI (embeddings & chat), Turbopuffer (vector search), Unstructured.io (document parsing)

### Key Integrations

- **OpenAI**: Embedding generation and chat completions
- **Turbopuffer**: Vector database for semantic search
- **Unstructured.io**: Document parsing and chunking
- **AWS S3**: File storage via Active Storage
- **Stripe**: Payments and subscriptions
- **Twilio**: SMS/WhatsApp messaging
- **Slack**: Team communication
- **Zendesk**: Ticket management
